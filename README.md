## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome. No build tools or installation are required.

## Publish free with GitHub Pages
1. Create a public GitHub repository, for example `keerthi-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish. Your website URL will appear in the Pages section.
